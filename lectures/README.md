## 命名规范

```
lectures/L{讲次两位数字}_{中文主题}.md
```

例：`L01_课程概览与分词.md`、`L02_资源核算与张量基础.md`

- 讲次用两位数字（`L01` 而非 `L1`），保证排序正确、扩展到 L10 后不混乱
- 主题用中文短语，控制在 12 字内，取该讲最核心的概念
- 不使用空格、冒号、括号等特殊字符，避免链接转义问题

## 这是什么

CS336 是一门"从零构建语言模型"的高强度实践课：实现分词器、Transformer、优化器，学 GPU/Triton 内核、分布式训练、Scaling Laws、推理与评测，再走完 Common Crawl 数据清洗、去重，以及 SFT / RLHF / RLVR 后训练。

课程本身没有官方中文材料，机器翻译的自动字幕读起来非常吃力。这份笔记做三件事：

1. **恢复结构** —— 把流水式的转写稿重组成有论证链的章节，配速查表、易错点、自测题。
2. **校对术语** —— 修正语音识别造成的译名错误（`碎骨激活函数` → **SwiGLU**、`H减net` → **MegaByte**、`CLAPTON` → **Kaplan**、`1750亿` → **150B** 这类），全篇留痕标注。
3. **保留时间戳** —— 每个段落都带 `**mm:ss**` 锚点，有疑问可以直接回原视频定位。

## 校对说明

转写稿由自动语音识别生成，错误率不低。本笔记以人工校对的字幕文本为准逐段订正，主要修正四类问题：

- **英文专名**：`TSUMARSELHERMAN` → Tatsu、Marcel、Herman；`NOMSHAZIER` → Noam Shazeer
- **技术术语**：`丛林构建` → 从零构建；`碎骨激活函数` → SwiGLU；`减脂` → 剪枝
- **数字**：`1750亿` → 150B；`100亿个Token` → 15 万亿 token；`11万6104` → `116 104`（ASCII `t`=116、`h`=104）
- **同音字**：`便利索引` → 遍历索引；`此表` → 词表

**刻意保留、未作修改的部分**：讲师本人的口误与玩笑（例如两处 `10²⁴` 与 `10²⁵` 混用、Shazeer 论文结尾"归于上天的恩典"的原话、"庞大而美妙的混乱局面"），因为这些是原始表达的一部分，加注说明而不擅改。

**时间戳完整性**：每份笔记的段落时间戳与原转写稿逐一比对，确保零遗漏、零虚构。
